GUIA DE L’EINA · REVISADA EL 15/10/2026

Per a què serveix?

Estima quin preu futur equivaldria a un import actual si una taxa d’inflació hipotètica es repetís cada any.

Com introduir les dades

  • Import actual (€)
  • Inflació anual (%)
  • Anys

Comprova les unitats dels camps abans de calcular. Pots canviar una dada i repetir el càlcul per comparar dos casos.

Fórmula i mètode

Preu futur = import actual × (1 + taxa anual ÷ 100)^anys.

Exemple resolt

Un producte de 100 € amb una inflació constant del 3% durant 2 anys passaria a costar 106,09 €. L’augment acumulat és de 6,09 €.

Com interpretar el resultat

La taxa la tries tu; l’eina no consulta l’IPC ni prediu els preus. La cistella personal i els preus de cada producte poden evolucionar de manera diferent.

Dubte freqüent

El càlcul mostra el valor actual dels diners futurs?

No. Mostra el preu equivalent futur. Per descomptar inflació d’un import futur cal dividir pel factor acumulat.
