Equació de segon grau

Resol equacions del tipus ax² + bx + c = 0.

Introdueix les dades i prem Calcular.

GUIA DE L’EINA · REVISADA EL 15/10/2026

Per a què serveix?

Resol una equació en la forma ax² + bx + c = 0. Escriu els tres coeficients amb el signe corresponent, inclosos els zeros.

Com introduir les dades

  • a
  • b
  • c

Comprova les unitats dels camps abans de calcular. Pots canviar una dada i repetir el càlcul per comparar dos casos.

Fórmula i mètode

Discriminant D = b² − 4ac. Si D és no negatiu, x = (−b ± √D) ÷ (2a). El coeficient a no pot ser zero.

Exemple resolt

Per x² − 5x + 6 = 0, introdueix a = 1, b = −5, c = 6. D = 1 i les solucions són 3 i 2.

Com interpretar el resultat

Si D és negatiu, l’eina indica que no hi ha solucions reals. No mostra arrels complexes. Amb D = 0 hi ha una arrel doble.

Dubte freqüent

Què faig si a és zero?

Ja no és una equació de segon grau. Cal resoldre l’equació lineal bx + c = 0.
