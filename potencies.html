GUIA DE L’EINA · REVISADA EL 15/10/2026

Per a què serveix?

Calcula una base elevada a un exponent. Serveix per productes repetits, creixements geomètrics i exponents negatius.

Com introduir les dades

  • Base
  • Exponent

Comprova les unitats dels camps abans de calcular. Pots canviar una dada i repetir el càlcul per comparar dos casos.

Fórmula i mètode

a^n representa multiplicar a per si mateix n vegades quan n és un enter positiu. Per a diferent de zero, a^(−n) = 1/a^n.

Exemple resolt

2^5 = 32. Amb base 2 i exponent −3, el resultat és 1/8 = 0,125.

Com interpretar el resultat

Algunes combinacions no tenen resultat real, com una base negativa elevada a 0,5. Els valors molt grans poden superar el rang del navegador.

Dubte freqüent

Què passa amb un exponent zero?

Una base no nul·la elevada a zero dona 1. L’expressió 0^0 té interpretacions diferents segons el context matemàtic.
